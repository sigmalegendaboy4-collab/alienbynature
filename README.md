# Сайт (AlienByNature)

Статический сайт: один файл `index.html` (вход по логину/паролю, содержимое зашифровано внутри файла).
Сервер, база данных и сборка не нужны. Нужен только **HTTPS** (на GitHub Pages и Netlify он есть автоматически).

## Вариант 1. Netlify (быстрее всего)
1. Откройте https://app.netlify.com/drop
2. Перетащите на страницу эту папку (или распакованный zip).
3. Через пару секунд получите адрес вида `https://что-то.netlify.app`.
   Имя можно сменить: Site configuration → Change site name.

## Вариант 2. GitHub Pages
1. Создайте репозиторий на GitHub (лучше новый).
2. Загрузите все файлы из папки в корень репозитория (Add file → Upload files).
   Файл `.nojekyll` тоже должен попасть в репозиторий.
3. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

## Важно
- **Не загружайте** в репозиторий/на Netlify файл с логинами и паролями (`new_users_100.txt`).
  Раздайте их пользователям отдельно.
- На бесплатном GitHub Pages репозиторий должен быть публичным. Содержимое сайта зашифровано,
  но сам `index.html` всё равно скачивается любым желающим.
- Обновление списка пользователей: в админке нажмите экспорт, скачайте новый `index.html`
  и замените им старый файл (Netlify: перетащить заново; GitHub: Upload files → заменить).
